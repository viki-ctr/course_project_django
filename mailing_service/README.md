# Сервис управления рассылками (Django)

Проект представляет собой веб-приложение для управления email-рассылками с возможностями:
- Создания/редактирования рассылок
- Управления получателями
- Отправки сообщений
- Сбора статистики

##  Основные функции

- **Аутентификация пользователей**:
  - Регистрация
  - Вход/выход
  - Профиль пользователя

- **Управление рассылками**:
  - CRUD операции для рассылок
  - Статусы рассылок (Создана, Запущена, Завершена)
  - Планирование отправки

- **Статистика**:
  - Отчеты по попыткам отправки
  - Общая статистика на главной странице

- **Безопасность**:
  - Разделение прав (пользователи/менеджеры)
  - Ограничение доступа к данным

## Технологии

- Python 3.8+
- Django 4.0+
- PostgreSQL (или SQLite для разработки)
- Redis (кеширование)
- Bootstrap 5 (интерфейс)

##  Установка

1. Клонировать репозиторий:
```bash
git clone https://github.com/ваш-username/название-проекта.git
cd название-проекта
```

2. Установить зависимости
3. Создать файл .env на основе .env.example и заполнить переменные:
SECRET_KEY=ваш-secret-key
DEBUG=True
DB_ENGINE=django.db.backends.postgresql
DB_NAME=your_db_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432
4. Применить миграции: python manage.py migrate
5. Создать суперпользователя: python manage.py createsuperuser
6. Запустить сервер: python manage.py runserver
